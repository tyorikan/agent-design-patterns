# Spec: Security Posture & IAM Advisory A2A Agent (`cli03-a2a-interoperability`)

## 1. 目的（Why）
組織内の他の開発チームのエージェント（言語やフレームワークを問わないオーケストレーター）から、標準プロトコル **A2A（Agent2Agent）** 経由で IAM ロール権限リスク診断および CVE 影響照会をリモート呼び出しできるようにする。

## 2. 公開インターフェース
- **Agent Card（能力発見）**: `GET /a2a/app/.well-known/agent-card.json`
- **A2A JSON-RPC エンドポイント**: `POST /a2a/app`（A2A v1 および Gemini 連携用 v0.3 互換インターフェースを両方公開）
- **ADK 標準 API**: `/run`, `/run_sse`（同一の `shared://session` を共有）

## 3. ツール契約
1. `evaluate_iam_binding(role_name: str, principal_type: str = "serviceAccount") -> dict`
   - 付与しようとしている IAM ロール（`roles/owner`, `roles/editor`, `roles/aiplatform.user` 等）のリスクレベルと最小権限の代替ロールを返す。
2. `lookup_security_advisory(advisory_id: str) -> dict`
   - 既知のセキュリティ勧告 ID に対する影響範囲と推奨パッチ手順を返す。
