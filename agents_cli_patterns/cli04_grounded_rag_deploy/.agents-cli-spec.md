# Spec: Grounded Architecture Policy RAG & Production Deploy (`cli04-grounded-rag-deploy`)

## 1. 目的（Why）
社内アーキテクチャ標準・設計ガイドラインに関する問い合わせに対し、必ず検索根拠（ドキュメント ID と抜粋）を伴って回答し、コーパスに存在しない規定については推測せず「該当規定なし」と回答するグラウンディング型エージェントを、ローカル開発環境から Cloud Run / Agent Runtime 本番環境まで同一コードでデプロイ可能にする。

## 2. コア設計（Pluggable RAG + Global/Regional 分離）
1. **Retriever の差し替え可能性**:
   - `AGENT_SEARCH_DATA_STORE_ID` 未設定時: `LocalCorpusRetriever`（インメモリの決定論的検索・課金ゼロで単体テスト可能）
   - `AGENT_SEARCH_DATA_STORE_ID` 設定時: `AgentSearchRetriever`（Google Cloud Agent Search / Discovery Engine REST API 経由で本番コーパスを検索）
2. **LLM ロケーションとランタイムリージョンの分離**:
   - モデル推論（`gemini-3.8-flash`）: `GOOGLE_CLOUD_LOCATION=global`
   - Agent Runtime / セッションストア: `GOOGLE_CLOUD_AGENT_ENGINE_LOCATION`（`us-central1` 等のリージョン）
