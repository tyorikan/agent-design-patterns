# Spec: Cloud Cost Anomaly Triage Agent (`cli02-evaluation-gate`)

## 1. 目的（Why）
FinOps 担当者が日次のクラウド利用料急増を検知した際、原因ワークロードの切り分けと削減シミュレーションを一貫した品質で行えるようにする。また、プロンプトやモデルを変更するたびに `agents-cli eval` と CI 閾値ゲートで品質退行（リグレッション）を自動検出する。

## 2. ツール契約（Tool Contracts）
1. `inspect_cost_spike(service_name: str) -> dict`
   - 指定されたサービス（`compute`, `bigquery`, `llm_inference`）の直近コスト急増メトリクスと主要要因を返す。未登録サービス名にはサポート対象一覧を含む案内辞書を返す。
2. `estimate_savings(monthly_spend_usd: float, reduction_rate_percent: float) -> dict`
   - 月額費用と削減見込み率（%）から、月間・年間の削減見込み額（USD）を決定論的に計算する。

## 3. 継続的評価基準（Evaluation Gate Thresholds）
- `custom_response_quality`（LLM-as-a-Judge / 1〜5 点）: 平均 `4.0` 以上
- `non_empty_structured_answer`（決定論的 Python 関数 / 0.0〜1.0）: 平均 `1.0`
- `agent_turn_count`（決定論的 Python 関数）: 1 以上のターン記録が存在すること
