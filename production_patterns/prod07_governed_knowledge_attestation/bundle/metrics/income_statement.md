# Definition

年度別の損益サマリは、FP&A ハンドブックの基準に従い[^fpa-handbook]
[認識売上計算](../computations/recognized_revenue.md) および
[セグメント別粗利計算](../computations/gross_profit.md) の 2 つの承認済み計算結果から構成されます。

本ドキュメントは指標の意味と前提のみを説明し、実数値の算出は必ずリンク先の `Attested Computation` を実行して取得してください。
売上計上の細則は [収益認識ポリシー](../policies/revenue_recognition.md) を参照してください。

[^fpa-handbook]: FP&A 財務レポーティングハンドブック
